# Divi Love — free layout library

Ready-made Divi 5 layouts for [Divi Connect](https://divilove.com/). The plugin reads
`index.json`, then a group file under `groups/`, then one layout file per insert; every file
is hash-verified before it reaches a site. Thumbnails live under `thumbs/`.

This tree is generated from the Divi Connect repository (`build/lib_publish.py`) — edit
nothing here by hand; it is overwritten on the next publish.
